# Python 类型转换速查卡（不用背，忘了就查）

> 核心一句话：**输入转 float，输出用 f-string**。
> 因为 f-string 会自动把数字变文字，所以今天你其实只需要记住 `float()` 一个函数。

## 为什么需要转换

Python 不会自动把「长得像数字的文字」变成数字。

```python
input()        # 你输入 10，拿到的是 "10"（字符串），不是数字
"10" + "3"     # 输出 "103"（拼接），不是 13
10 + 3         # 输出 13
```

## 三种场合，三种写法

| 什么时候 | 用什么 | 例子 | 结果 |
|---|---|---|---|
| 要算数 | `float(x)` / `int(x)` | `float("3.14")` | `3.14` |
| 要拼进句子 | `str(x)` 或直接用 f-string | `f"结果 {10+3}"` | `结果 13` |
| 要判断真假 | `bool(x)` | `bool(0)` | `False` |

**Day2 的计算器只需要第一行**：`a = float(input(...))`。输出用 f-string，不用手动 `str()`。

## 常见坑（踩过一次就记得了）

| 写法 | 结果 | 说明 |
|---|---|---|
| `int("3.14")` | ❌ 报错 | 带小数点的字符串不能直接转 int，用 `float()` |
| `int(3.9)` | `3` | 直接砍掉小数，**不是**四舍五入 |
| `float("abc")` | ❌ 报错 | 文字转不成数字（以后学 try/except 处理）|
| `"10" * 3` | `"101010"` | 字符串重复三遍，不是 30 |
| `type(x)` | — | 不确定类型时，随时打印它看看 |

## 5 分钟自测（照着敲一遍，不用记）

```python
print(type("10"))        # <class 'str'>
print(type(10))          # <class 'int'>
print(type(10.0))        # <class 'float'>
print("10" + "3")        # 103
print(10 + 3)            # 13
print(float("3.14"))     # 3.14
print(int(3.9))          # 3
print(f"结果 {10 + 3}")   # 结果 13  ← f-string 自动转，不用 str()
```
