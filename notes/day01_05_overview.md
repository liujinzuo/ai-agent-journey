## Day1 · 环境与版本管理（不是语法，是工具）

这一天的产物不是代码，是**一套能干活的环境**。四个工具各管一件事：

| 工具 | 它管什么 | 一句话理解 |
|---|---|---|
| Python 3.13.14 | 跑代码 | 解释器，把 `.py` 文件读进来执行 |
| Git 2.56.0 | 记录每一次改动 | 本地的时间机器，随时能回到任何一个提交 |
| GitHub | 把记录备份到云端 | 远端仓库，也是你半年后唯一的硬证据 |
| VS Code | 写代码的编辑器 | 编辑 + 运行 + 调试，还能让 AI 进去结对 |

**必须会的 6 条命令**（这是你后面 160 天每天都要用的）：

```bash
git status            # 看现在是什么状态（最常用，不确定就先敲它）
git add -A            # 把改动放进「待提交」篮子
git commit -m "说明"   # 把篮子里的东西存成一张快照
git push              # 把快照传到 GitHub
git log --oneline -3  # 看最近 3 次提交
git diff              # 看具体改了哪几行
```

**PATH 是什么**：你在终端敲 `python`，系统去 PATH 列出的那些文件夹里找叫 `python.exe` 的文件。找不到就报「不是内部或外部命令」。所以安装时那句「Add python.exe to PATH」是关键。

**.gitignore 的作用**：里面写的文件 Git 一律不看。你的仓库里它挡住了 `.venv/`（几千个文件）和 `.env`（存 API 密钥，**绝对不能传上去**）。

## Day2 · 变量、类型、输入输出

### 2-1 变量是「标签」，不是「盒子」

**一句话**：`a = 10` 不是「把 10 装进盒子 a」，而是「给 10 这个值贴上一张叫 a 的标签」。所以给同一个名字重新赋值 = 把标签撕下来贴到别处。

```python
name = "liujinzuo"
name = 30            # 同一个名字，现在指向数字了，原来那个字符串没人管了
print(name)          # 30
```

**什么时候用**：理解这一刻之后，你就不会奇怪「为什么改了这个变量，那个变量也变了」——它们可能只是贴在同一块值上。

### 2-2 四种基本类型

| 类型 | 是什么 | 例子 |
|---|---|---|
| `int` | 整数 | `42`、`-7` |
| `float` | 小数 | `3.14`、`10.0` |
| `str` | 字符串（文字） | `"agent"`、`'你好'` |
| `bool` | 真 / 假，只有两个值 | `True`、`False` |

```python
print(type(42))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type("agent"))  # <class 'str'>
print(type(True))     # <class 'bool'>
```

**什么时候用**：报 `TypeError` 时，第一反应就是 `print(type(x))` 看看它到底是什么。

### 2-3 `input()` 拿到的永远是字符串 ← Day2 第一大坑

**一句话**：不管用户在键盘上敲的是 `10` 还是 `abc`，`input()` 交回来的都是**文字**。

```python
raw = "10"            # 相当于 raw = input()
print(raw + "3")      # 103    ← 字符串拼接，不是加法
print(float(raw) + 3) # 13.0   ← 转成数字才能算
```

**什么时候用**：任何要从键盘读数字的地方，一律写 `float(input("提示: "))`。

### 2-4 运算符

| 写法 | 结果 | 说明 |
|---|---|---|
| `10 / 3` | `3.3333...` | 除法，**结果永远是小数** |
| `10 // 3` | `3` | 整除，砍掉小数部分（不是四舍五入） |
| `10 % 3` | `1` | 取余数，判断奇偶全靠它 |
| `2 ** 10` | `1024` | 乘方 |

### 2-5 f-string：把变量塞进句子

**一句话**：字符串前面加个 `f`，里面用 `{}` 挖洞，把变量名填进去。

```python
a, b = 10.0, 3.0
print(f"{a} + {b} = {a + b}")     # 10.0 + 3.0 = 13.0
```

**什么时候用**：所有需要拼字符串的地方。别再用 `"a" + str(x)`，f-string 又短又不会漏 `str()`。

## Day3 · 列表与字典（Agent 里 90% 的时间在这两个上面）

### 3-1 列表 list：有序、能改、能切

```python
nums = [1, 2, 3, 4, 5]
nums.append(6)        # 末尾加一个
print(nums)           # [1, 2, 3, 4, 5, 6]
print(nums[0])        # 1    第一个，索引从 0 开始
print(nums[-1])       # 6    最后一个，负数从右边数
print(nums[:3])       # [1, 2, 3]   切片：要前三个
```

**什么时候用**：**有顺序、会重复**的东西——对话历史、检索到的文档、工具列表，全是 list。

### 3-2 字典 dict：按键取值

**一句话**：列表用「第几个」取，字典用「名字」取。键（key）不一定是数字，可以是字符串。

```python
tool = {"name": "search", "args": {"q": "agent"}}
print(tool["name"])                  # search
print(tool.get("timeout", "没设置"))  # 没设置   ← 键不存在时不报错，给默认值
```

**`get()` 和 `[]` 的区别**：`tool["timeout"]` 键不存在会直接报 `KeyError` 崩掉；`tool.get("timeout", "没设置")` 不崩，返回你给的默认值。

**什么时候用**：一件东西的**多个属性**——一个工具调用的名字和参数、一条消息的角色和内容，都是字典。

### 3-3 计数万能一行

```python
text = "agent tool agent model agent"
counts = {}
for w in text.split():
    counts[w] = counts.get(w, 0) + 1     # 取不到就当 0，然后 +1 写回去
print(counts)                            # {'agent': 3, 'tool': 1, 'model': 1}
```

**什么时候用**：词频、投票、统计任何“某个东西出现了几次”。

### 3-4 推导式：`[产出 for 变量 in 来源 if 条件]`

**一句话**：把「建空列表 → 循环 → 满足条件就 append」三行压成一行。读法：**先说产出，再说从哪来**。

```python
nums = [1, 2, 3, 4, 5, 6]
print([n for n in nums if n % 2 == 0])   # [2, 4, 6]        过滤
print([n * n for n in nums])             # [1, 4, 9, ...]   加工
print({k: v * 2 for k, v in counts.items()})  # 字典版，产出写「键: 值」
```

**三条防错规则**：
1. `if` 在 `for` **后面** = 过滤，结果**可能变少**
2. `if...else` 整体放**前面** = 二选一，数量不变
3. 字典版必须写 `键: 值`，来源必须写 `.items()`

**什么时候用**：一层就够。**嵌套两层以上就写回普通循环**——三个月后你自己也读不懂。

## Day4 · 控制流与异常

### 4-1 分支 if / elif / else

```python
score = 5
if score <= 3:
    print("神")
elif score <= 5:      # 上面的条件不成立才看这里
    print("稳")
else:                 # 全都不成立才走这里
    print("勉强")
```

**注意**：`elif` 是「否则如果」，从上往下只走第一个成立的；判断相等用 `==`，`=` 是赋值。

### 4-2 `break` 和 `continue`

| 关键字 | 干什么 | 记法 |
|---|---|---|
| `break` | **整个循环立刻结束** | 掀桌子走人 |
| `continue` | **只跳过本次，下一圈照跑** | 这一题跳过，继续下一题 |

```python
kept = []
for n in range(1, 6):
    if n == 2:
        continue     # 2 被跳过
    if n == 5:
        break        # 到 5 就整个结束
    kept.append(n)
print(kept)          # [1, 3, 4]
```

### 4-3 异常 try / except

**一句话**：把「可能失败的代码」放进 `try`，失败时别让程序崩，走 `except` 兜底。

```python
def read_number(raw):
    try:
        return float(raw)     # 可能失败：'abc' 转不成数字
    except ValueError:
        return None           # 不崩，交回一个「读不出来」的信号
```

| 关键字 | 作用 |
|---|---|
| `try` | 把可能失败的代码放进去 |
| `except` | 出错时做兜底处理 |
| `else` | 没出错才执行 |
| `finally` | 总会执行，用于收尾 |

**为什么 Agent 必须这么做**（今天最值钱的一句）：

> **异常是给程序看的，错误信息才是给模型看的。**

工具调用不捕获 → 整个 Agent 崩掉；捕获之后把错误变成字符串喂回模型 → **模型会自己决定重试还是换个工具**。这就是“Agent 能自我纠错”的底层机制。

## Day5 · 函数与模块化

### 5-1 最小骨架

```python
def add(a, b):          # def + 名字 + 参数 + 冒号
    """两数相加。"""      # 文档字符串：一句话说明（可省，但要写）
    return a + b        # 缩进四格，return 把结果交出去

print(add(3, 4))        # 7
```

三条规则：**缩进就是边界**；**定义时不执行，调用才执行**；**`a`、`b` 是占位符，取什么名都行**。

### 5-2 `return` vs `print`（最容易混）

| | 结果去哪 | 谁能用 |
|---|---|---|
| `return a + b` | 交回调用处 | **程序**能接住继续算 |
| `print("hello")` | 打到屏幕 | 只有**人**看得见 |

**关键**：没有 `return` 的函数，返回值一律是 **`None`**。屏幕上出现字 ≠ 函数交出了结果。

```python
def say_hello():
    print("hello")

x = say_hello()     # 屏幕上有 hello，但 x 拿到的是 None
```

### 5-3 默认参数

```python
def greet(name, greeting="你好"):
    return f"{greeting}，{name}"

greet("liujinzuo")              # 你好，liujinzuo
greet("liujinzuo", "早上好")     # 早上好，liujinzuo
```

**规则**：带默认值的参数必须放在最后。

### 5-4 一个函数只干一件事

```python
def calculate(a, b):
    return {"+": a + b, "-": a - b, "*": a * b, "/": a / b, "//": a // b}

def print_results(a, b, results):
    for op, value in results.items():
        print(f"{a} {op} {b} = {value}")
```

**为什么 `calculate` 返回字典而不是自己 print**：因为「算」和「显示」是两件事。算出来的东西将来网页要用、接口要用、测试要用，它们都不需要终端。

**这个设计真正的回报**：你加一条 `"//"`，`print_results` 一个字都不用改——因为它遍历字典，不关心里面有哪些运算符。**好代码不是因为写得短，而是因为改一处的时候别处不用跟着改。**

### 5-5 `if __name__ == "__main__":`

**一句话**：只有**直接运行**这个文件时才执行 `main()`；被别人 `import` 进来时不执行。

```python
if __name__ == "__main__":
    main()
```

**什么时候用**：每个能单独跑的脚本底部都写这一行，Day6 开始多文件互相引用时会天天见。

## 一张总速查表（最常用的 15 行）

```python
# 类型
type(x)                          # 看类型
int("3")  float("3.14")  str(42) # 转换（int("3.14") 会报错）

# 字符串
f"{a} + {b} = {a+b}"             # f-string
"a b c".split()                  # 按空格切成列表
",".join(["a", "b"])             # 列表拼成字符串

# 列表
nums.append(x)  nums[0]  nums[-1]  nums[:3]  len(nums)

# 字典
d["k"]  d.get("k", 默认值)  d.items()  d.keys()  d.values()

# 推导式
[x*2 for x in nums if x > 3]
{k: v*2 for k, v in d.items()}

# 计数
counts[w] = counts.get(w, 0) + 1

# 异常
try: ... except ValueError: ...

# 函数
def f(a, b=2): return a + b
```

## 最容易忘的五条（背这五句就够）

1. `input()` 拿到的是**字符串**，算数前必须 `float()`
2. 判断相等用 `==`，`=` 是赋值
3. 没有 `return` 的函数返回 **`None`**；`print` 不是 `return`
4. 列表**有序能改**（按位置取），字典**按键取值**（按名字取）
5. 推导式一律写 `[产出 for 变量 in 来源 if 条件]`，**先产出，后来源**
