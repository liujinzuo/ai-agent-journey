## 今天要记住的知识点

| 概念      | 写法                           | 说明                                    |
| ------- | ---------------------------- | ------------------------------------- |
| 变量      | `name = "小明"`                | 起名用小写字母+下划线，不能用中文标点                   |
| 整数 / 浮点 | `10` / `3.14`                | `type(10)` 是 int，`type(3.14)` 是 float |
| 字符串     | `"abc"` 或 `'abc'`            | 引号要成对                                 |
| 布尔      | `True` / `False`             | 首字母必须大写                               |
| 算术      | `+ - * / // % **`            | `//` 整除，`%` 取余，`**` 幂                 |
| 输入      | `input("提示语")`               | **返回的永远是字符串**                         |
| 类型转换    | `float(x)` `int(x)` `str(x)` | 算数前必须转                                |
| 格式化     | `f"{a} + {b} = {a+b}"`       | 前面加 f，变量放花括号里                         |
| 输出      | `print(x)`                   | 可以一次打印多个，用逗号分隔                        |
