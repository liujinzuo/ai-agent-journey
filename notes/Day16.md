# Day16 · 回头看

> 一句话：**模型读句子时不是从头到尾顺着读一遍，而是每个词都回头看全句，自己判断"我该重点关注谁"——这个动作叫注意力。**

---

## 一、接上昨天

昨天讲到：模型算出一张概率表，然后抽签。

但还有个问题没答：**那张概率表是怎么算出来的？**

这就要看句子进了模型之后发生了什么。今天不推导公式，只建三个直觉。

---

## 二、生活里的场景：你读长句也会回头看

读这句话：

> 小猫没有跳过栅栏，因为**它**太累了。

读到「它」，你的眼睛会**往回扫**，去找「它」指的是谁——你不会平均地看每个词，你会重点看「小猫」，顺便看一眼「累」。

再读：

> 小猫没有跳过栅栏，因为**它**太宽了。

同一个「它」，你的眼睛这次往回找的是「栅栏」。

**你脑子里的这个"回头看、挑重点"的动作，就是注意力机制在模仿的东西。** 不是我给它起名叫注意力，是它真的在做这件事。

## 三、先看一个笨办法：只数词

如果模型只做一件事——把句子里有哪些词数一遍，会发生什么？

跑一下：

```powershell
cd C:\Users\22155\ai-agent-journey
.venv\Scripts\python.exe -X utf8 code\day16_attention.py
```

演示一的输出：

```
  句子A：狗 咬 人
  句子B：人 咬 狗
  A 的词袋：{'狗': 1, '咬': 1, '人': 1}
  B 的词袋：{'人': 1, '咬': 1, '狗': 1}
  两个词袋一样吗？True
```

**意思完全相反，词袋一模一样。**

原因很直白：数词的时候把顺序扔了。「狗咬人」和「人咬狗」用的是同样三个词，各出现一次。

所以模型要做的第一件事不是"数词"，而是**搞清楚谁跟谁有关系**。

## 四、注意力：让每个词自己去挑该看谁

演示二就是干这件事的。它拿「它」跟全句每个词算一个分数，再变成百分比：

```
句子A：小猫 没有 跳过 栅栏 因为 它 太 累 了
  「它」在看谁：
    小猫　　  78.7%  ███████████████████████████████
    累　　　  10.7%  ████
    跳过　　   2.2%  █
    栅栏　　   1.9%  █
    ...

句子B：小猫 没有 跳过 栅栏 因为 它 太 宽 了
  「它」在看谁：
    栅栏　　  84.9%  ██████████████████████████████████
    小猫　　   5.2%  ██
    ...
```

同一个「它」，两句话指向不同的东西：

| 句子 | 「它」主要看谁 | 为什么 |
|---|---|---|
| …因为**它**太累了 | 小猫 78.7% | 会累的是动物 |
| …因为**它**太宽了 | 栅栏 84.9% | 会宽的是东西 |

**关键在这里：没有人写"累了指小猫、宽了指栅栏"这条规则。** 是模型拿「它」和全句每个词算了一遍相关性，分数高的那个自然占大头。

它凭什么知道"累"跟"小猫"更配？凭预训练——它读了海量文本，见过太多次这种搭配。（昨天讲的预训练，在这里第一次派上用场。）

## 五、位置编码：给每个词贴座位号

注意力有个副作用：它对每个词一视同仁地算相关性，**本身不知道谁在前谁在后**。

演示三：

```
    位置 1：狗        位置 1：人
    位置 2：咬        位置 2：咬
    位置 3：人        位置 3：狗
```

词一样，座位号不一样。「狗」在 A 坐 1 号，在 B 坐 3 号。

模型看到的不是一袋词，而是「**这个词 + 它在第几位**」。这个座位号就是**位置编码**。

> 这就是为什么当年它第一次打败旧方法：旧方法（RNN）只能一个词一个词顺着读，词离得远就记不住；注意力可以一步跨到句子里任何一个词，位置靠座位号补上。

## 六、全貌：三句话说完 Transformer

不用记 Q、K、V，不用记多头，不用推导矩阵。今天只要这三句：

1. **每个词回头看全句**，给每个词打一个相关性分数（注意力）。
2. **按分数把别人的信息捞过来**，混进自己身上，再带着这个新版本往下走。
3. **这个动作叠几十层**，最后才轮到"猜下一个字"（昨天讲的那张概率表）。

所以昨天那张概率表不是凭空来的：它是几十层"回头看 + 混合"之后的结果。

---

## 七、今天两个新概念

1. **注意力（attention）** —— 每个词对全句每个词算一个相关性分数，分数越高，从这个词拿的信息越多。**它不是规则，是算出来的。**
2. **位置编码（position encoding）** —— 给每个词贴一个"第几位"的标记，因为纯注意力本身分不清顺序。

> 今天不讲 Q/K/V、多头、残差、层归一化。想做 Agent 不需要会推导这些，知道它们在干什么就够了。

## 八、验收

一道题：

> 你问模型：「小明把苹果给了小刚，因为他饿了。」
>
> 模型回答：「小刚饿了。」——它没有搞错。但换成「因为他拿不动了」，模型会答「小明拿不动了」。
>
> 它没被教过「饿」和「拿不动」分别指谁。**它是凭什么分出来的？**

**答：靠注意力算出的相关性，而这个相关性来自预训练。**

拆成两步看：

1. **算相关性**：模型把「他」和句子里每个词两两算分。「饿」跟「小刚」（接收者）配得多，「拿不动」跟「小明」（给出者）配得多——分数一归一化，权重就压到不同的词上。
2. **这些搭配规律从哪来**：不是人写的，是预训练时从海量文本里统计出来的。「他饿了 → 那个没拿到东西的人」这种语感，模型见得足够多，就成了权重里的一部分。

一句话收口：**注意力负责"在句子里找谁相关"，预训练负责"凭什么觉得相关"。**

### 顺便划清一条界线

| 这是 | 不是 |
|---|---|
| 注意力在算"谁跟谁相关" | 模型在"理解"你的意思 |
| 相关性来自统计规律 | 来自逻辑推理 |

所以它会被"相关"骗：句子里如果一堆跟答案无关但统计上常一起出现的词，它照样会被带偏。以后学提示词工程、检索，很大一部分工作就是**帮它把相关的东西放在近处、把无关的东西清走**。
